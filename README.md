A lightweight Google Chrome extension that automatically scrolls to the next video when a YouTube Short finishes playing.

---

## ✨ Features

- **Hands-Free Auto-Scroll**: Detects when a video finishes and seamlessly scrolls to the next Short.
- **SPA & Dynamic Navigation Support**: Listens for YouTube's single-page application route updates and video stream updates.
- **Extension Popup Toggle**: Easily enable or disable auto-scrolling on demand via the toolbar popup.
- **Privacy First**: Operates entirely locally within your browser with zero data collection or tracking.

---

## 🚀 Quick Start (Installation)

1. Download, open Google Chrome and navigate to chrome://extensions/.

2. Enable Developer mode using the toggle switch in the top-right corner.

3. Click Load unpacked in the top-left corner.

4. Select the youtube-shorts-autoscroll folder.
